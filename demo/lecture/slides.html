The idea: walk downhill

  • The loss L(w) measures how wrong the model is
  • The gradient points uphill
  • So take a step the other way, then check again

The update rule

w  ←  w − η · ∇L(w)

  • η (eta) is the learning rate: the size of each step
  • ∇L(w) is the gradient of the loss at the current weights

Example.  w = 2.0,  gradient = 4.0,  η = 0.1

New weight:  2.0 − 0.1 × 4.0 = 1.6

Choosing the learning rate

  • Too small: it works, but slowly
  • Too large: each step overshoots and the loss diverges
  • Just right: fast drop, then flat

Stochastic gradient descent

  • Full batch: all 50,000 training examples for one step
  • Mini-batch: a random 64 examples per step
  • One epoch = 782 steps
  • Each step is noisy, but far cheaper

Today's example

Batch size: 64

Learning rate: η = 0.01

Training set: 50,000 examples

Summary

  • Gradient descent walks downhill on the loss
  • The learning rate η sets the step size
  • Mini-batches make each step cheap
