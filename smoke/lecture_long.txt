Today we are going to talk about gradient descent, which is the workhorse of modern machine learning. The idea is simple. We have a loss function that measures how wrong our model is, and we want to find the weights that make that loss as small as possible. At every step we compute the gradient of the loss with respect to the weights. The gradient points in the direction of steepest increase, so we move the weights a small amount in the opposite direction. How far we move is controlled by the learning rate. If the learning rate is too large, the updates overshoot and the loss can diverge. If it is too small, training takes forever. In practice we do not compute the gradient over the whole data set. Instead we use a small random batch of examples, which is called stochastic gradient descent. In today's example the batch size is sixty four and the learning rate is zero point zero one. One common improvement is momentum, which keeps a running average of past gradients so that the updates do not zigzag across narrow valleys. Another is to decay the learning rate over time, starting large and ending small. Remember that homework three is due on Thursday, and it asks you to implement momentum from scratch.
